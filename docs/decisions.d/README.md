# Decisions log fragments

One file per pull request, `YYYY-MM-DD-verify-<topic>.md`, holding one row
per decision in the table format of fundingmachine-core's
`docs/DECISIONS_LOG.md`:

    | 2026-10-16 | verify | What was decided | Why, and under which ruling | this pull request |

Standing rulings are recorded only by the Awards session in
fundingmachine-core (`rulings-ownership`); this repository follows them and
records none. These rows are the Verifier session's own decisions under
`delegated-decisions`.
