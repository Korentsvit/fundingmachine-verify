# Plan

Owner: the Verifier session. Scope: this repository only. Not building the
ledger, capture, capital, or the website.

## Targets

End states, with no dates. Standing ruling `scoreboard-wake-hold` (17 October
2026) retired the dated gates this plan used to carry.

| Target | Measure |
| --- | --- |
| A verdict on every anchor the Provenance Ledger commits, from its public record, with the block headers relied on, under `verdicts/` | Ledger anchors with a verdict, of anchors committed (the scoreboard line) |
| The verifier conformance suite, which any third party can run | Conformance cases, the Ledger's `validation-conformance/v0` cases agreed |
| The hosted verifier page's specification, handed to the website side through the owner | `docs/HOSTED_PAGE.md`, `hosted-page/0`; handed over on 17 October |

## Sources

* The Provenance Ledger's anchors are public since 17 October 2026, without a
  login: https://fundingmachine-ledger.vercel.app/api/anchors (the listing,
  `anchor-record/v0`, and every file by path and SHA-256). Verdicts read them
  there (`verdicts/`), cross-checked against the Ledger's `anchors` branch.
* The repositories the anchors cover (fundingmachine-core, Knowledge-goblin,
  the Ledger) are private. This session reads them, which lets it compare
  anchored leaves with the files at the commits each anchor records; a
  public reader checks a file it holds against the anchored hashes instead.
* Still to come from the Ledger: a schema and published location for key
  rotation (V-22), and the submission index on its main branch (V-24).
