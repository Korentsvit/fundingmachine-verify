Provenance Ledger anchors, verified in this browser

This page checks every anchor in the Provenance Ledger's public mirror, at a commit you name, with fm-verify running here in your browser. No server checks anything. It shows the verdict, the Bitcoin block headers the verdict relied on, and everything else it relied on. The command line gives the same verdict, and remains the proof.

What this page fetches, and who learns what
  • GitHub (raw.githubusercontent.com) serves the mirror's files at the commit named. It learns the commit, your IP address and that this page asked.
  • The Ledger's record (fundingmachine-ledger.vercel.app), if the box is ticked, is asked for each file by its SHA-256. It learns the same.
  • The explorers (mempool.space, blockstream.info) are asked for the blocks the proofs name. They learn the block heights, which show roughly when the anchors were made, your IP address, and that the request comes from this page.
  • Nothing else leaves this page. It keeps no record of what was checked, and a reload forgets everything.
